# Step 2 · Readings

Each size measured three times with a micrometer: the readings are in the files, and a model, `model/specimen.py`, takes their mean as the value and their standard error as its uncertainty.

Run every command from this folder.

```console
$ samplekit -c width,thickness
$ samplekit samples/steel-01.md view
$ samplekit status
```

The home page explains this step: [readings and their statistics](https://zelyph.github.io/SampleKit/latest/index.html#readings-and-their-statistics).

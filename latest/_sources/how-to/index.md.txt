# How-to guides

Short recipes for a task in your own project. Each assumes you have done the
[tutorial](../tutorial/index.md), or know what it shows, and gives the
commands in order.

| Guide | What it does |
| --- | --- |
| [Move existing data in](move-existing-data.md) | From a spreadsheet, a CSV file or notes by hand into sample files, and several collections under one common root |
| [A first model](first-model.md) | A Python model that computes values from the ones you measured |
| [An export for a paper](export-for-a-paper.md) | Tables and figures with the labels and digits a paper wants, and how to make them again |
| [Check a project in continuous integration](continuous-integration.md) | A job that fails when a file is wrong or a value is not current |
| [Share a project](share-a-project.md) | Your samples in git, for a colleague or another computer |
| [Upgrade from an older SampleKit](upgrade.md) | Samples written by SampleKit 0.2 |

For what each command, key and setting does, see the
[reference](../reference/index.md); for why SampleKit works as it does, the
[explanations](../explanations/index.md).

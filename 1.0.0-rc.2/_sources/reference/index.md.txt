# Reference

Every fact in one place, to look up. The command line, the Python API and
the TUI's keys are generated from the code, so they say what the version you
read them for does.

- [The command line](cli.md): every command, its arguments, options and
  examples.
- [The Python API](python.md): what `import samplekit` offers.
- [The TUI's keys](tui.md): every key, screen by screen, and the marks.
- [Configuration](configuration.md): every section and key of `.samplekitrc`.
- [Filters](filters.md): every form `-f` and a saved query take.
- [Sample files](sample-files.md): what a sample file may hold, and how it is
  written.
- [Written files](written-files.md): the columns and cells of a CSV, TSV or
  JSON file written from a table, and how a value not current is said.
- [Fingerprints](fingerprints.md): how each fingerprint of a sample file is
  computed, to check one by hand.
- [Exit codes](exit-codes.md): what each exit code of `samplekit` means.
- [Glossary](glossary.md): the words SampleKit uses, each in a sentence or
  two, with the page that explains it.

Configuration¶

.samplekitrc is a project's configuration, in TOML. It is optional: a folder of samples without one is read with the defaults below.

Where it applies¶

  • A sample follows the nearest .samplekitrc: in its own folder, else in the closest folder above, with what that file imports, wherever the command runs from. Configurations are combined only by import.

  • A folder below a project with a .samplekitrc of its own is a separate project.

  • Paths written in .samplekitrc are relative to the file itself, imported ones to the file that declares them.

  • What list, the completion and the TUI's f offer is the configuration of the folder a command runs from, or of its target.

  • --rc PATH uses another configuration for one command; --show-rc prints the configuration, model and Python a command would use.

  • The file is checked each time it is read. An unknown section or key, a value of the wrong type, or a name that refers to nothing declared is an error naming the line and the nearest valid name. A configuration with an error is set aside and said; the samples it covers are read without it.

Top level¶

Key

Type

Default

Meaning

Example

schema_version

integer

required, in every file

The version of the configuration's format: 1. A file importing another writes its own

schema_version = 1

import

folder or file, or a list

none

What this file takes, merged beneath it: a folder's .samplekitrc, or a file of any name; relative to this file, absolute, or starting with ~. A list is merged in order, a later one over an earlier one

import = ["..", "figures.samplekitrc"]

The sections below are all optional.

import¶

  • What is imported: everything but [model] path and class, which stay each file's own. [model] python is imported.

  • The merge rule: key by key, this file winning. A table (a section, a [property.NAME], a profile) merges key by key, recursively; any other value (a number, a text, a list) replaces the imported one whole.

  • A list: each is merged in order, a later one over an earlier one, and this file over all. A file listed twice is merged once.

  • Chains: the imported file may import another. A file importing itself, directly or through others, is an error naming the files.

  • Errors: a folder without a .samplekitrc, or a path naming nothing, is an error naming the importing file. The imported file must be valid on its own, its schema_version written.

  • Paths: a relative [collection] files, [export.*] output, [query.*] directory, [model] python, or [matplotlib] style file or font reads from the file declaring it. [collection] include and exclude are patterns on the collection's own files and apply as written. Each project's own decide which files are its samples, whichever folder a command names: the patterns of a folder above never reach into a project inside it.

  • {project}, in [collection] files and [export.*] output, is the folder of the project a sample follows, written from the file declaring it (data/ana from the root; . in the project's own file): files = ["{project}/photos/{name}*"], output = "exports/{project}/overview.csv". {project}.tsv in the project's own file writes ..tsv, which validate notes.

  • Where each comes from: samplekit list queries (profiles, exports, figures) marks each name local, with the imported file, or local over it; --show-rc names the files imported; samplekit validate notes a declaration identical to the imported one.

A precision is a format specifier, written as in Python: ".3f" (three decimals), ".2e" (scientific notation), ".4g" (four significant digits), or a list of two, [".3f", ".4f"]: the value's, then the uncertainty's. ".17g" writes every digit a value carries, and an uncertainty's too: 0.8787328442349305 is written as it is.

[collection]¶

Which files are samples, and where a sample's own files are.

Key

Type

Default

Meaning

Example

recursive

boolean

true in a project

Read the folders below the folder named too. A folder outside any project is read alone

recursive = false

include

list of patterns

["*.md", "*.MD", "*.markdown"]

The files read

include = ["*.sample.md"]

exclude

list of patterns

[]

The files skipped. samplekit list skipped lists them

exclude = ["draft-*"]

files

list of folders or patterns

[]

Where a sample's own files are: a folder, searched for files whose name starts with the sample's; or a pattern holding {name}, the sample's file name without .md; {project} is its project's folder (see import)

files = ["photos", "raw/{name}/**"]

Patterns are globs: * any characters within a name, ? one character, ** any number of folders, [0-9] one of a set, {a,b} either. A pattern holding a / is matched against the path from the project's folder; without one, against the file name.

[unit."SPELLING"]¶

How a unit is shown, in each style. The key is the unit as the files write it, quoted. SampleKit never converts units: a unit no section names is shown as written.

Key

Type

Default

Meaning

Example

plain

text

the spelling

The unit in the plain style

plain = "°C"

any style's name

text

the spelling

The unit in that style

math = '^\circ\mathrm{C}'

A spelling no section names is shown as written: the sections are display forms, never a closed list of units. What validate reports is a file whose unit contradicts the one [property.*] declares.

[style.NAME]¶

A style says how a kind of document writes: named by [render] style, --style, an export's and a figure's style, and the variants of [unit.*] and [property.*], [unit.g] latex = '\gram'. plain is built in; latex, markdown and html are given, and a [style.latex] changes the given one key by key. A style of units and symbols alone may be declared empty, [style.figure].

Key

Type

Default

Meaning

Example

property

text or false

"{value} ± {uncertainty} {unit}"

How a property is written, with {value}, {uncertainty}, {unit} and {symbol} in the style's forms; in a document, false writes its two columns. A unit placed inside it, \SI{…}{{unit}}, is written in each cell and not in the column's header

property = '\SI{{value} \pm {uncertainty}}{{unit}}'

uncertainty

text

the number

The piece {uncertainty} stands for in property and unitless, with {uncertainty} the number in it; written only where a value has an uncertainty

uncertainty = ' \pm {uncertainty}'

unitless

text

property, its unit empty

How a property with no unit is written, instead of property

unitless = '\num{{value}{uncertainty}}'

missing

text

"" in a document

An absent value

What text is escaped for: latex, html, markdown, or a table of replacements, escape = { "<" = "&lt;" }. A template and the style's own lines and forms are written as they are

escape = "latex"

[matplotlib]¶

matplotlib's own settings, by their matplotlib names, for every figure of the project. Quote a dotted name.

Key

Type

Default

Meaning

Example

any matplotlib setting

as matplotlib takes it

matplotlib's

That setting

"axes.grid" = true

"figure.figsize"

two numbers

matplotlib's

A figure's size, in centimetres

"figure.figsize" = [15, 10]

style

text or list

none

matplotlib's style sheets, by name or as .mplstyle files, applied in order before the section's own settings, which win

style = ["seaborn-v0_8-paper", "figures.mplstyle"]

fonts

text or list

none

Font files, or patterns of them, that matplotlib learns before it draws: a font that travels with the project

fonts = ["fonts/*.otf"]

Other sizes keep matplotlib's units: points for fonts and lines. A name matplotlib does not know, a value it refuses and a date are errors; backend and interactive are refused. A style sheet matplotlib does not have, a file that is not there and a pattern that finds none are errors too. A .mplstyle file and a font are read from the file declaring them.

SampleKit makes a few choices of its own, and gives way where the project declares the setting, in this section or in a style sheet:

Setting

SampleKit's choice

lines.marker, or marker in axes.prop_cycle

a round marker on each point of a scatter and a line

lines.markersize

the points of a box drawn at size 3

errorbar.capsize

caps of 3 points on the error bars

legend.fontsize

a small legend, where it is placed outside

A scatter draws no line between its points, whatever lines.linestyle says. plot --no-project-style ignores the section, and a figure's own matplotlib.

[colors]¶

[history]¶

The project's history, kept in .samplekit/history/.

Key

Type

Default

Meaning

Example

shared

boolean

not set

Whether git carries the history with the samples: true lets git see what must travel and keeps out what each computer makes for itself; false hides the history from git. Not set, a new history is hidden, and one shared by hand is left as it is.

shared = true

Imported as any key: a root declaring it shares the history of every project importing it. See Share a project.

A complete example¶

schema_version = 1

[model]
path = "model/specimen.py"
class = "Specimen"
python = ".venv"

[render]
table = "boxed"
figure_style = "figure"

[collection]
recursive = true
exclude = ["draft-*"]
files = ["photos", "machine/{name}/*"]

[unit."degC"]
plain = "°C"
math = '^\circ\mathrm{C}'
figure = "°C"

[style.math]
property = '${value} \pm {uncertainty}$ {unit}'

[style.figure]

[property.tensile_strength]
symbol = "Rm"
symbol_math = 'R_\mathrm{m}'
precision = ".0f"

[query.steels]
filter = 'material == steel'

[profile.overview]
columns = [
  { field = "name", label = "Specimen" },
  { field = "material", label = "Material" },
  { field = "tensile_strength", label = "Tensile strength", header = "Rm" },
]
sort = ["material", "-tensile_strength"]

[export.overview]
profile = "overview"
format = "csv"
output = "out/overview.csv"

[figure.curves]
kind = "line"
x = "curve.strain"
y = "curve.stress"
group = "material"
legend = "outside"

[matplotlib]
"axes.grid" = true

[colors]
outdated = "#ff8800"
